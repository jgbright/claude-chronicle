Features

🔍

Session Browsing

Auto-discovers all your Claude Code sessions with full-text search and project filtering.

🎨

Dual Themes

Claude and Copilot themes with Markdown, syntax-highlighted code, and thinking blocks.

✂️

Non-Destructive Editing

Delete, collapse, annotate, and reorder blocks. Original sessions are never modified.

📦

Single-File Export

Export to a self-contained HTML page with all assets inlined. Share it anywhere.

🔒

Privacy First

Runs entirely on your machine. No cloud, no accounts. PII sanitization on export.

⚡

Single Binary

One Go binary with the React SPA embedded. No runtime dependencies to install.

Quick Start

Option A: explicit download (Linux amd64)

# Download the latest release
curl -fL https://github.com/jgbright/claude-chronicle/releases/latest/download/claude-chronicle_linux_amd64.tar.gz | tar xz

# Browse your sessions
./claude-chronicle serve

# Export a session
./claude-chronicle export -session <id> -o session.html

Option B: auto-detect OS/arch (compare this option)

# Auto-detect OS/arch and download matching release binary
OS=$(uname -s | tr '[:upper:]' '[:lower:]'); ARCH=$(uname -m); [ "$ARCH" = "x86_64" ] && ARCH=amd64; [ "$ARCH" = "aarch64" ] && ARCH=arm64; curl -fL "https://github.com/jgbright/claude-chronicle/releases/latest/download/claude-chronicle_${OS}_${ARCH}.tar.gz" | tar xz

# If release assets are unavailable, run directly with Go
go run github.com/jgbright/claude-chronicle/cmd/chronicle@latest serve
