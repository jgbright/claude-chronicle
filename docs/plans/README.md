# Plans

This directory holds proposed plans for future work on Claude Chronicle.

Plans are **not commitments** — they're ideas that have been explored, analyzed, and documented for future reference. A plan may be adopted as-is, modified, partially implemented, or shelved indefinitely.

## Naming convention

Use descriptive kebab-case filenames: `frontend-domain-reorganization.md`, `export-pdf-support.md`, etc.

## Status tracking

Each plan includes a `Status` field in its header:

- **proposed** — documented but not started
- **in-progress** — actively being implemented
- **completed** — fully implemented
- **shelved** — decided against or deferred indefinitely
